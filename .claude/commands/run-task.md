argument-hint: TASK 번호 (예: TASK-002)
---

대상 작업: $ARGUMENTS. 너는 **진행 담당(메인)**이다. 직접 코드를 쓰지 않고 에이전트에게 나눠 준다.

1. `docs/tasks/`에서 $ARGUMENTS를 읽고, 문서의 "팀 나누기" 표를 확인한다. 브랜치를 만든다 (`feat/<task-번호>-<짧은 이름>`).
2. **테스트**: `test-writer` 에이전트에게 맡긴다. 돌아온 한국어 요약표와 질문을 **그대로 승현에게 보여 주고 멈춘다.** 승현이 "승인"이라고 하기 전에는 3으로 가지 않는다. 고칠 점을 주면 `test-writer`에게 다시 맡긴다.
3. 승인되면 PR 초안(`Claude outputs/PR-<TASK>-draft.md`)에 승인 날짜와 요약표를 기록한다.
4. **구현**: 표에 적힌 담당(`server-engine`, `server-graphs`, `mobile`)에게 맡긴다. 서로 파일이 겹치지 않으면 동시에 맡긴다. 에이전트가 "문서에 없어요" 질문을 돌려주면 멈추고 승현에게 보여 준다.
5. **점검**: `reviewer` 에이전트에게 맡긴다. "고칠 것 있음"이면 해당 담당에게 다시 맡긴다.
6. 승현에게 보고: 무엇을 했는지, AC 결과 표, 돌연변이 점수, 문서에 없어서 정한 것, 승현이 직접 할 일(한 줄씩 설명한 명령). PR은 승현이 요청하면 만든다.

`docs/`는 누구도 고치지 않는다.
