## 4. 확정 토큰 (11-06, 캔버스 "Tripfriends UI v1")
**컨셉 "동그라미 친 한 컷"**: 사진 한 장씩 같이 보고, 마음에 든 곳에만 주황으로 동그라미를 친다. 길 위에서는 지금 할 일 한 장만 또렷하게. 키워드: 한 컷(사진 먼저) · 동그라미(주황은 표시펜) · 또렷함(상태는 글자, SOS·입력창은 늘 같은 자리)

### 4-1. 색 (§1·§2에 더하는 것)
| 토큰 | 값 | 규칙 |
|---|---|---|
| `on-brand` (추가) | `#1A1A1A` | 주황 면 위 글자·아이콘. **주황 위 흰 글자 금지** (3.13 탈락) |
| `muted` (조정) | `#666C7A` | 보조 글자 |
| 의미 색 이름 | `ok`/`ok-bg`, `warn`/`warn-bg`, `alert`/`alert-bg`, `danger` | 값은 §2 그대로 (`danger`=SOS 전용) |
| `sunset-start` / `sunset-end` | `#FF8C42` / `#FFA140` | 로고 타일에만 (§1과 같은 값) |
- 주황은 **화면 면적 4% 이하**: 고른 것, 지금 한 가지, 주 버튼에만. 주황으로 쓴 글자는 없음. **4%는 주 버튼 1개를 빼고 센다** (11-06)
- `scrim` (추가) `rgba(26,26,26,0.40)`: 시트·대화상자 뒤 어두운 막에만
- **비활성**: `opacity`로 흐리게 하지 않는다. `bg-2` 바탕 + `muted` 글자 (4.78)
- DM Mono는 숫자·시각에만. 한글이 섞인 글은 `font-text`
- 사진 자리표시 그라데이션(슬레이트·라일락 등 차가운 톤)은 토큰이 아니라 임시 값

### 4-7. 고르기·입력 (11-09, 캔버스 보드 ⑧⑨)
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `sel-bg` / `sel-ring` | `brand-soft` / 안쪽 2px `brand` | 고른 칸 |
| `radio` | 24 | 칸의 선택 표시 |
| `action-bar` | 68 | 시트 아래 확정 버튼 줄 |
| `row-alt` / `row-drop` | 64 / 52 | T-06 대안 칸 / [빼고 가기] 칸 |
| `thumb-sm` | 44 | 칸 안 사진 자리 |
| `field-error-bg` / `field-error` | `alert-bg` / `alert` (별명) | 틀린 입력 칸과 오류 문장 (색 + 아이콘 + 문장) |
| `field` | 64 | 날짜·시각·제목 입력 칸 높이 |
| `tab-day` | 보이는 36, 누르는 44 | 날 고르는 탭 |
| `notice-limit` | 모서리 16 | 넘침 안내 상자 |
| `sheet-form` | 500 | 고정 일정 입력 시트 |
- **고르기 방식**: 여러 안 중 하나를 고를 때는 **칸을 눌러 고르고(`sel-*` + `radio`), 확정은 시트 아래 주 버튼 하나**. 고르기 전 주 버튼은 비활성(`bg-2` + `muted`) → 화면에 주황 버튼이 없음 = 아직 아무것도 안 바뀜
- **주 버튼 높이는 52로 통일** (`btn`). 여행 만들기 화면의 56도 52로
- 장소 이름 뒤 조사(이/가, 은/는, 을/를)는 받침에 따라 바꾼다 (앱·서버 대본 공통)
