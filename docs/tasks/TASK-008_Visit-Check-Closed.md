## A. 영업 확인 (T-05, FR-14·AC-07)
| # | 규칙 |
|---|---|
| A1 | **대상**: 다음 일정 장소의 영업 사실(`opening_hours` fact) 상태가 `unverified` 또는 `unknown`이고, 그날 그 장소에 확인 기록(`visit_checks`)이 없다 |
| A2 | **때**: 다음 장소 출발 **30분 전부터 도착 전까지** (`leave_at − 30 ≤ at < next.start`). 이때 `compose_screen` 입력 `hours_checked=False`, `arriving=True` (TASK-006 Q25 중립값을 이 경우만 해제) |
| A3 | **메인 결정은 compose 순위대로**: 출발 10분 전부터는 순위 5(T-02)가 이기고, T-05는 짝 표대로 **T-02의 보조**로 남는다 (SCREEN-001 §5 "T-02 → T-05(영업 확인 전이면)") |
| A4 | **T-05 카드 값**: `place`(이름), `facts`(상태 필수), `source_type`, `checked_at`(없으면 "확인한 적 없음"), `map_url`(구글 지도 장소 검색, 좌표), 버튼 [열었어] [닫혔어]. 문구: "가기 전에 열었는지 볼래?" — **영업 여부를 추측해 쓰지 않는다** |
| A5 | **답 저장**: `POST /places/{place_id}/visit-checks` 본문 `{day_id, at, was_open}` → `visit_checks` 기록 + 그날 그 장소의 fact를 **`status=confirmed`, `source_type="user"`, `checked_at=at`**으로 덮어씀 (열었어면 영업 중으로, 닫혔어면 그날 휴무로). 원본 데이터는 남긴다 |
| A6 | 같은 날 같은 장소는 **한 번만** 묻는다 (기록이 있으면 A1 대상 아님) |

## B. 닫힘 대안 (T-06, FR-15·AC-08)
| # | 규칙 |
|---|---|
| B1 | [닫혔어] → G2 사건 `type="closed"`, `dedupe_key="closed:{day_id}:{place_id}"`, 심각도 높음 → 대안 계산 → `awaiting` (TASK-007 B-1 전이표 재사용: check 대신 visit-check가 사건을 연다) |
| B2 | **대안 후보**: 같은 `category`, 코스에 없음, 그날 닫힘 확인 기록 없음, **예정 도착 시각에 영업 중**(fact `confirmed` 또는 `unverified`. `unknown`은 제외), 닫힌 장소에서 **1.5km 안**. 닫힌 장소에서 가까운 순 **최대 3곳** |
| B3 | 제안마다: 닫힌 곳을 그 장소로 바꾼 남은 코스를 `compose_courses`(TASK-007 `start` 인자)로 다시 계산. `summary` = 장소 이름·거리·이동 변화 분(`+4분` 등)·영업 사실(상태 필수), 고정 일정을 못 지키면 그 대안은 뺀다 |
| B4 | **[빼고 가기] 제안** 하나를 항상 덧붙인다 (닫힌 곳만 빼고 다시 계산). 대안이 0곳이면 이것만 + "근처에 열린 비슷한 곳이 없어" |
| B5 | [이걸로] = accept(TASK-007 B-3과 같은 반영), [그대로 둘게] = dismiss (일정 그대로, 닫힌 곳도 그대로) |
| B6 | NowView: `awaiting` closed 사건이면 `compose` 순위 4 → 메인 **T-06**, 짝 T-03. T-06 카드 = `{type:"T-06", event_id, closed:{place_id,name}, proposals[]}` |
