날짜 목록 3가지(여행 전: 계획 전·계획 완료 섞임 / 오늘 여행 중 / 모두 계획 완료 → 주 버튼 없음), 지난 날 포함(데모 기기 여행 + `past_days`), 계획 대화 후보 카드 3가지(Google Maps · 늘 열림 Tripfriends · 밤거리 추천 시간대), 읽기만(미확인·모름 섞인 날), 새 여행 확인 시트. **파일 이름에 화면 이름**(예: `01-날짜목록-여행전.png`)
