## 8. 학습 카드 (결정권자용)
1. **지도**: 비트마스크 DP는 "장소 n곳을 어떤 순서로"를 2^n개 부분집합으로 푼다. n이 하나 늘면 일이 두 배
2. **핵심 개념**: 시간 복잡도 O(n²·2ⁿ) · 입력 상한으로 최악을 막기 · 측정표로 근거 남기기
3. **직접 해보기**: PR의 측정표에서 n=10과 n=15 시간을 비교해 보기
4. **내 말로**: "왜 꼭 갈 곳을 5곳으로 막았나?" / "15곳이 넘으면 어떻게 하나?"

## 포트폴리오 포인트
- 점검용 데이터로 지수 시간 위험을 **재현 → 원인 → 측정 → 상한** 순서로 막음. 숫자(n별 시간)로 근거
- 폰 스크린샷 전·후 비교로 디자인 일치를 보여 줌
- 예상 면접 질문: "DP를 쓰면서 입력 크기를 어떻게 막았나요?" → "n=25에서 5분 멈추는 걸 재현했고, n별 시간을 측정해 15곳 2초 이내를 확인한 뒤 꼭 갈 곳 5곳·DP 15곳 상한을 입력 단계에 넣었다"
