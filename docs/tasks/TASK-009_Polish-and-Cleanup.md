## B. 문구 정리
| # | 할 것 |
|---|---|
| B1 | **조사 함수** 하나: 이/가, 은/는, 을/를, 으로/로. 받침 없음 → 가·는·를·로, ㄹ 받침 → "로", 그 밖 받침 → 이·은·을·으로. 영문·숫자로 끝나면 TASK-008 §17처럼 받침 없음으로 본다. **앱(TS)과 서버(Python)에 같은 규칙, 같은 경계 표로 테스트** |

| B3 | 출처 표시: `source_type`을 화면에 원문으로 쓰지 않는다. `demo` → "데모 데이터", `user` → "내가 확인", 그 밖 값은 "출처 정보" (TASK-010에서 실제 출처 이름으로) |
| B4 | 닫힘 대안 `reordered=true`일 때 앱이 따로 그리던 "순서를 바꿔야 들어가" 안내를 **뺀다** (서버 이유 문장이 정본, 두 번 보임 해결) |
