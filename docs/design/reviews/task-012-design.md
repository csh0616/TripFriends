| 글자 문구 | **승인된 세 가지만**: 「Google 계정으로 로그인」「Google 계정으로 가입」「Google 계정으로 계속」. 번역은 허용·권장 |
| 금지 | "Google"만 쓴 버튼 · 로고만 있는 버튼 · 흑백 G · 직접 만든 아이콘 · 밝은/어두운/중립 말고 다른 바탕 위의 4색 G. 가이드에 없는 쓰임은 Google의 사전 서면 동의가 필요 |
| 비중 | 다른 로그인(Apple·카카오)이 들어오면 Google 버튼이 그보다 작거나 약하면 안 된다 (크기·무게 비슷하게) |

**시안의 G는 같은 모양으로 그린 것이다.** 구현은 Google 내려받기 묶음의 SVG를 그대로 쓰고 시안과 맞춰 본다.

### TASK-012가 말한 [Google로 저장]은 못 쓴다
"저장"은 승인 문구에 없고, "Google"만 쓰는 것도 금지다. 그래서 **버튼 = 「Google 계정으로 계속」, "저장"이라는 뜻 = 시트 제목**으로 나눴다. 「계속」은 새 계정 연결과 이미 있는 계정 로그인을 한 문구로 덮는다. 이 때문에 §C1("[Google로 저장] [나중에]")과 AC-8("Google로 연결")의 버튼 이름을 고쳐야 한다.

Google 로고는 이 버튼에만 쓴다. 가이드에 적힌 쓰임이 버튼이라서, 프로필 메뉴 상태 줄 같은 다른 쓰임은 피했다.

## 4. 화면별

### ③-T12a 저장 권유 (§C1)
- 제목 → 본문 → 보조 한 줄 → [Google 계정으로 계속] → [나중에]. 주황 버튼 없음(Google 버튼은 흰색). 이 시트의 주 행동이 Google 버튼이다.
- [나중에] 뒤엔 자동으로 다시 묻지 않는다(§C1). 프로필 메뉴 [저장하기]로 다시 올 수 있다(§C5).
- 스크림을 누르면 [나중에]와 같다고 가정했다.

### ③-T12b 어느 여행 (§C4)
- 칸 2개 = **②-07 고르는 칸**: 누르면 sel-bg(#FFF1E8) + 안쪽 2px #FF5A00 고리 + radio 24(채움 + 체크). 확정은 아래 주 버튼 하나, 고르기 전 비활성(TASK-009 A2와 같은 [이걸로 할래]).
- 칸 높이 84, 안쪽 좌 12·우 14, 썸네일 오사카 44(s44), 3줄: 어디서 온 여행(12/16·600·muted) / 이름(15/22·600) / 날짜 · 진행(12/16·500·muted).
- **기본으로 고른 칸이 없다.** 데이터가 걸린 선택이라 사용자가 직접 고르게 했다.
- 고르지 않은 쪽은 "지우지 않고 보관"이라고 본문에 적었다(§C4·ADR-016 3-1: archived).
- 이 시트는 **두 쪽 모두 여행이 있을 때만** 뜬다고 가정했다. 익명 쪽만 있으면 시트 없이 계정으로 옮기고(§C4), 계정 쪽만 있으면 그대로 로그인.

### ③-T12c 프로필 메뉴 (§C5)
- 앱에 있는 아바타 시트(TASK-006 §15: 제목 없음, [처음부터 다시]·[닫기])를 **그대로 두고 맨 위에 연결 상태 카드를 더했다.** 카드: bg-2, 모서리 20, 안쪽 14/16, 아바타 흰 원 44(기존 "내 프로필" 아이콘).
- 저장 안 됨: 카드 아래 주 버튼 [저장하기] → **T12a(저장 권유 시트)가 올라온다.** Google 버튼은 그 시트에만 있다.

## 6. PM이 정해 줄 것 (v1 때 질문 — 전부 답을 받았다, §8-1)

1. **버튼 이름**: §C1의 [Google로 저장]·AC-8의 "Google로 연결"을 「Google 계정으로 계속」으로 고칠지 (§2). 승인 문구는 로그인·가입·계속 셋뿐.
2. **프로필 메뉴 [저장하기]**: 저장 권유 시트를 다시 올리는 것으로 그렸다. 바로 Google로 보내려면 그 버튼이 Google 버튼 규칙(모양·승인 문구)을 따라야 한다.
3. **어느 여행 시트에서 빠져나가는 길**이 없다(스크림을 눌러도 안 닫힘). 잘못된 Google 계정으로 들어왔을 때를 위해 보조 버튼 [연결 취소](익명 그대로, §6 "연결 취소")를 넣을지.
4. **아바타는 여행 중 지도에만 있다.** [나중에]를 누른 사용자가 여행 전(날짜 목록·계획 중)에는 [저장하기]를 누를 곳이 없다. 날짜 목록 머리 왼쪽(지금 비어 있음)에 아바타를 둘지.
5. **[처음부터 다시]**: TASK-006 §15가 "실제 여행 데이터가 생기면 확인 한 번 추가"라고 했다. 이제 여행이 저장되니 확인을 넣을지(이번엔 앱 그대로, 확인 없음으로 그림).
6. **어느 여행 칸의 정보**(이름·날짜·진행): 서버가 계정 쪽 여행의 진행 상태("4일 중 3일 계획 완료")까지 주는지 API 확인이 필요하다. 안 주면 이름 + 날짜만.
7. **내가 더한 문구 3개**(§1 표의 "내가 더함")를 쓸지. 뺄 수 있다.
8. **③-F01(시작 · 로그인 시안)**: ADR-016이 "처음엔 익명, 로그인 화면 없음"으로 정해서 이 시안이 쓸모없어졌을 수 있다. "기록"(쓰지 않음)으로 바꿀지.
9. **연결 실패·취소 안내**: §6 표는 "익명 상태 그대로"라고만 적었다. 안내 문구 화면은 그리지 않았다.
