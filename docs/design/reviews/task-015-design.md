## 1. 숙소 입력 2·3단계 (a1~a4)

### 1-1 흐름

| 단계 | 화면 | 사용자 | 저장 |
|---|---|---|---|
| ① 이름 | ①-06 (그대로) | 이름 입력 → 결과 줄 고름 | `kind: place` |
| ② 주소 | **a1** | ①에서 못 찾음 → 앱이 **같은 글**로 주소를 다시 찾아 줄 목록을 보여 줌(다시 안 쳐도 됨). 줄을 고름 | `kind: address` (장소 ID + **입력한 글**) |
| ③ 지도 | **a2** | a1 아래 [여기 없어? 지도에서 찍기] → 지도를 길게 눌러 핀 → [여기로 정했어] | `kind: pin` (**찍은 좌표** + 이름표) |
| 막힘 | **a3** | 이름 · 주소 둘 다 못 찾음 → **바로** [지도에서 찍기] (a1을 거치지 않아도 됨) | — |
| 막힘 | **a4** | 지도가 안 뜸 → [다시] · [숙소 없이 계속] | `lodging: null` |
- a1 · a3의 [지도에서 찍기]는 둘 다 **a2**로 간다. [건너뛰기]는 ①-05와 같다(`lodging: null`, T-08 "오늘 일정 끝")
- 고른 뒤는 ①-05와 같다: 숙소 칸에 **place = 이름 · address = 입력한 주소 글 · pin = 이름표(없으면 "지도에서 찍은 곳")** (제안)

## 2. 코스 카드 → 실제 지도로 크게 보기 (b)

**두 화면을 한 보드에**: 왼쪽 = ①-16 코스안 + 새 `btn-expand-map`, 오른쪽 = 크게 보기. 카드의 도식은 **그대로 가볍게 비교**하고, **누른 카드 하나만** 실제 지도를 띄운다(TASK-015 §D: 카드마다 지도를 띄우면 무거움).

| 부품 | 값 |
|---|---|
| 도식 카드 → 버튼 | 지금 도식(350×120 · r20)이 **통째로 버튼**(눌러 열림, aria "코스 지도 크게 보기"). 카드 크기 · 모양은 그대로 |
| `btn-expand-map` (제안) | ~~도식 오른쪽 아래 알약 28 · 흰 · sh-float~~ → **11-16 오후(§11): 도식 아래 요약 줄 오른쪽 끝** · bg-2 · 24 · 확대 아이콘 14 + "크게 보기" 12/16·600. 누를 수 있다는 **표시**일 뿐 눌러지는 영역은 도식 + 요약 줄 |
| 크게 보기 화면 | 전체 화면 지도(402×874). 상태 표시줄 영역까지 지도 |
| `map-close` | **닫기** 44 흰 원(sh-float) · × 아이콘 · 왼쪽 16 · 위 62 |
| 제목 알약 | 가운데 36 · 흰 · sh-float · 13/18·600 "**2**일째 · 느긋하게"(**N일째 숫자만 DM Mono 500**, §26) |
| SOS | 여행 중 지도와 같은 자리(오른쪽 위, 44) — 코스를 보는 중에도 도움은 닫히지 않는다 |
| 경로 | 주황 5 + 흰 테두리 9(②-06a와 같음). 도식과 같은 **실선** — 점선은 Google iOS에서 안 그려질 수 있다는 ADR-014 A1 메모 때문 |
| 핀 | ②-06a **번호 핀**(지름 28 · 흰 바탕 · #333333 2 · 번호 DM Mono 500 14) + 맨 끝 **숙소 집 마커**. **B6 규칙 재사용**(가림 순서 · 묶음 +N · 집 배지). 순수 함수가 계산해서 그림 |
| 이름표 | **핀마다 이름표**(5곳 이하일 때, 제안). 위 → 오른쪽 → 왼쪽 → 아래 후보에서 안 겹치는 곳, 다 안 되면 뺌(B6 그대로). **6곳 이상이면 이름표 없음**(번호 · +N · 집 배지는 그대로, §12 Q2). 계산은 카메라가 멈춘 뒤 · 닿으면 다음 후보(§12 Q4) |
| `map-scale` | **축척**: 오른쪽 아래 · 시트 위 10 · 폭 96 · 높이 30. 위 글자 **"500m"**(숫자만 DM Mono 500 12 · "m" Noto 12/600 · 흰 테두리 3) · 아래 **L자 눈금 막대**(#333333 2 + 흰 테두리 4.5 · 막대 폭 84). 막대는 "보기 좋은 거리"(100·200·500m·1km)로 고르고 폭 ≤ 120 |
| `course-bar` | 아래 시트 **168 = 아래 안전영역 34 포함**(안쪽 134 + 34 · 버튼 아래 34, §12 하-1) · r28 위 · sh-sheet. 이름 17/24·700 "느긋하게" · 보조 13/18·500 muted "5곳 · 이동 45분"(문장 속 숫자라 Noto) · **[이걸로 할래]** 52 주 버튼(①-16과 같은 글) |
| Google 로고 | SDK가 그린다. `mapPadding.bottom = 168` |
| 카메라 | **경로 전체가 보이게 맞춤.** 여백 위 = 머리줄 아래 + 이름표 높이 · 아래 = 시트 168 + 로고 · 좌우 **핀 가장자리에서 24 = 핀 중심 기준 38**(§12 Q1). TASK-014 `rehearsalCamera`의 맞춤 계산을 쓸 수 있는지는 frontend가 먼저(§D) |
| 지도 못 불러옴 | TASK-015 §6: **크게 보기를 닫고 도식 카드 그대로.** 알림 한 줄(`notice-info` "지도를 못 불러왔어")은 제안 — 조용히 닫기만 하면 눌렀는데 아무 일도 없어 보인다 |

**Q4. 39~41 이름표가 SOS 밑에 깔림 → 고치는 중이라니, 고칠 값을 정리한다.**
