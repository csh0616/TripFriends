## 4. 화면별

### ③-T14a 위치 안내 (D1 · A1)
- 아이콘 → 제목 → 본문(왜) → 사실 줄(저장 안 함) → [위치 켜기] → [나중에]. 주황 버튼 하나.
- [위치 켜기] → iOS 권한 창("앱을 사용하는 동안 허용"). [나중에] → 닫고 시계만(A2). **스크림을 누르면 [나중에]와 같다**고 가정했다.
- 바탕: 실제 여행의 오늘 여행 중 화면(①-18)이고, **내 위치 점 없음**.
- 데모 여행 · 계획 화면 · 앱 처음 켤 때는 이 시트가 안 뜬다(A1). 보드는 그 경우를 따로 그리지 않았다.

### ③-T14b1·b2 위치 꺼짐 (D2 · A2)
- 알약은 이동 상태 알약 아래. 시계만 쓰는 동안 계속 보인다(끊김 띠가 뜨면 §6-3).
- 누르면 설명 시트. **주 버튼 [설정 열기]** → 앱의 iOS 설정 화면. [닫기]는 시트만 닫는다. 자동으로 다시 묻는 시트는 없다(A2).
- 위치가 부정확해 그 값을 버릴 때(A4)도 같은 알약으로 알릴지는 §6-6.

### ③-T14c1·c2 날짜 목록 (D3 · C1)
- 코스를 고른 날(**계획 완료**) 줄에만 [미리 걸어 보기]. 오늘 · 지난 날 · 계획 전 날엔 없다. 데모 여행엔 없다(이미 데모 시계가 있다).

- 줄 위 84는 그대로 눌러서 코스 읽기만(①-17)으로 간다. 버튼은 아래 따로. 같은 카드 안이라 한 덩어리로 보인다.
- **주황 0**: 버튼은 흰 알약 + 회색 테두리라 날짜 목록의 주 버튼(① 맨 아래 [같이 고르기])을 안 가린다.

## 6. PM이 정해 줄 것

1. **권한을 이미 거절했거나 "나중에"를 눌렀을 때 iOS 동작.** (내 이해, 확인 필요) iOS는 한 번 거절하면 앱이 **다시 권한 창을 못 띄운다**(설정 앱에서만). 반대로 [나중에]는 iOS에 아직 안 물어본 상태라, 설정 앱에 앱의 "위치" 줄이 **없을 수 있다.** 그래서 알약 설명 시트를 둘로 나눌 수 있다: ⓐ 아직 안 물어봄 → 주 버튼 [위치 켜기](iOS 창을 띄움) ⓑ 거절함 → 주 버튼 [설정 열기]. 지금 보드는 ⓑ만 그렸다. ⓐ를 쓰면 D1과 거의 같은 시트가 된다. frontend가 `expo-location`의 권한 상태(`undetermined`/`denied`)로 갈라야 한다.
2. **문구 제안 확인**: §1 표의 (제안) 전부, 특히 D1 제목 "위치를 켜 둘까?"와 본문, D2 제목·본문, 연습 시계 이름, `Info.plist` 문장(말투 "…요").
3. **"위치 꺼짐" 알약과 끊김 띠가 같이 필요할 때**: 알약은 이동 상태 알약 아래(top 106)에 두었다. 끊김 띠(②-06b)가 위에 뜨면 겹치므로 **끊김 띠가 있는 동안은 알약을 숨기거나 띠 아래로** 내려야 한다. 어느 쪽인지.
4. **위치가 꺼졌을 때 [내 위치로 이동] 버튼**: 남겨 두었다. 누르면 같은 설명 시트(③-T14b2)가 뜨게 하자는 제안. 아니면 버튼을 숨긴다.
5. **연습 중 지도의 점**: "계획대로라면 지금 여기"(코스 위 시계 시각의 자리)로 읽히게 그렸다. 실제 내 위치처럼 보일 수 있어서, 연습 중 점의 색을 다르게 할지(예: 속이 빈 점).
6. **위치가 부정확해 값을 버릴 때(A4)**: 알약 "위치 꺼짐"과 다른 상황이다. 같은 알약에 "위치 확인 중"처럼 문구를 바꿀지, 알약 없이 시계만 쓸지(지금 그림은 그 상태를 안 그림).
7. **알림 "연습이라 저장하지 않았어"의 자리·사라짐**: 지도 위(top 200)에 뜨고 **몇 초 뒤 자동으로 사라진다**고 가정했다(①-25와 같은 방식). 연습 중 행동마다 매번 뜰지, 첫 한 번만 뜰지.
8. **[연습 끝내기]에 확인이 없다.** 연습은 저장이 없어서 확인 없이 바로 날짜 목록으로 돌아가게 그렸다. 시계를 끝까지 돌렸다 해도 같다.
9. **"바뀐 이유" 줄**: 연습 보드는 시계 판 때문에 시트가 낮아서 그 줄이 입력창 뒤로 가려진다. 시트를 끌어 올리면 보인다고 가정. 그 줄을 항상 보이게 하려면 시계 판을 시트 안(B7처럼)으로 넣고 시트를 ①-18 높이로 둔다 — 그러면 지도가 거의 가려진다.
10. **D5 ①-31의 이동 상태 알약 "다음까지 여유 있음"**: ②-06b의 free 상태 모양(bg-2 + ink)에 글자만 새로 붙였다(제안). 하루 끝에는 "다음"이 없으니 "오늘 일정 끝"이 더 맞을 수 있다.
11. **번호**: ①-29~31은 ①-28 다음 번호로 "여행 중" 줄에 넣었다(번호는 순서 규칙과 약간 어긋남). 번호를 흐름 순서대로 다시 매길지(①-22~28 보드 이름이 다 바뀜), 이대로 둘지.
12. **D3의 두 보드**: ①-08·①-09 모습에 버튼을 얹은 것이다. 확정되면 ①-08·①-09 자체를 이 모습으로 고치고 ③-T14c1·c2는 기록으로 둔다. 같은 줄이 ①-11(여행 중 2일째 날짜 목록)에도 있으면 [미리 걸어 보기]를 거기에도 넣어야 한다 — **지금 보드엔 ①-11을 안 고쳤다.**
