## 0. 한눈에
- **방향 확정(결정권자)**: 한 쌍 — **A 동글이 = 얼굴 · 표정용, C = 포즈 · 윤곽용.** 의견은 "A는 친근하지만 팔다리가 짧아 포즈가 안 보이고, C는 포즈는 좋지만 뻣뻣하고 무난함 → 둘이 더 융화되게".
- **C를 A 쪽으로 당겼다(새 C 5등신)**: ① 머리 키의 17% → 20% ② 팔 굵기 5.5 → 7.6 · 손 반지름 3.1 → 4.9 · 신발 폭 7.4 → 12.0, 팔 · 다리를 한 덩어리로 이어 관절이 둥글다 ③ 기본 서기에 팔꿈치 4° → 16° · 무릎 2° → 12° 굽힘 ④ 목도리 꼬리: 고정 삼각형 → 휘어 흐르는 띠(포즈마다 방향이 다름) ⑤ 얼굴은 A와 같은 식(눈 간격 · 입 크기가 머리 지름의 같은 비율).
- **조건 확인**: 새 C는 포즈 5개 모두 **팔이 머리를 가리는 칸 0개**(기본 서기 포함 6칸 모두 0). A는 2/5, 옛 C는 0/5. 팔꿈치 15°에서 손이 움직이는 양은 A 0.29 · 새 C 0.53 · 옛 C 0.78칸 — **새 C는 A보다 1.8배 또렷하고 옛 C보다는 68% 수준**이다(친근함을 얻은 대가).
- **어두운 바탕용 흰 윤곽 변형**을 만들었다(A · C 둘 다). 흰 테 ÷ 어두운 바탕 대비 14.7. 키 24px에서는 표정이 안 읽히고 사람 모양 · 핀 윤곽이 읽힌다.
- **포즈 5개는 비율을 확인하려는 프로토타입**이다. 실제 포즈 목록(15~20개)은 나중에 조사로 정한다(RESEARCH-003 §6-4).
- **아직 안 한 것**: 2분 따라 하기 시험 · 닮은 캐릭터 확인 · "A와 잘 어울리나"는 숫자가 아니라 눈으로 보는 일이라 PM · 결정권자 확인 필요(§8-1).

## 2. 캐릭터 값
- **시그니처 3가지**(변함 없음): ① 머리 위에 떠 있는 작은 핀(로고의 핀 · 잉크 · 머리 지름의 0.16 위) ② 주황 목도리(#FF5A00 + 꼬리 하나) ③ 작은 가방(#E5E7EB, 한쪽으로 삐져나옴).
- **몸**: 위 = 흰색, 반바지 = 잉크(#1A1A1A), 신발 = 흰색. 윤곽 = 잉크, 두께 = 키의 0.72%(최소 1.3px). 그림자는 #E5E7EB 타원 하나. 팔(어깨 팔 · 아래팔 · 손)과 다리는 윤곽을 한꺼번에 그린 뒤 색을 칠해서 마디마다 선이 끊기지 않는다(A에도 같은 방식).
- **얼굴**: 점 눈(반지름 = 머리 지름의 5.8%) + 입 곡선 + 연한 주황 볼(22%). 동물 · 귀 · 꼬리 없음. 얼굴을 그리는 식이 머리 지름만 받아서 A와 C의 얼굴은 같은 그림이다.
- **목도리 꼬리**: 끝으로 갈수록 가늘어지는 띠. 처음 뻗는 방향(`tail`)을 포즈마다 정하고 끝에서 바깥으로 휘며 살짝 출렁인다. 겹침 윤곽에는 안 넣는다.
- **비율표**(키 100 기준)

| A 동글이 | 2.5등신 | 40.0 | 21.0 | 31.0 | 9.0 · 29.0 | 5.4 · 13.0 | 0.29칸 (6px) |
| C 옛 6등신 | 6등신 | 16.7 | 34.5 | 49.8 | 5.5 · 14.6 | 3.1 · 7.4 | 0.78칸 (10px) |
| C 걷는이 5등신(새) | 5등신 | 20.0 | 32.5 | 49.0 | 7.6 · 19.0 | 4.9 · 12.0 | 0.53칸 (10px) |

- **주황 면적**(목도리 + 꼬리 면적, 402×874 화면): A는 키 96px일 때 0.05%, 240px일 때 0.31% · 새 C는 96px일 때 0.03%, 240px일 때 0.16%. 4% 규칙에는 여유가 있지만, 캐릭터가 나오는 화면(회고 카드 · 반응)은 주 버튼 주황과 합쳐서 센다. (윤곽선 두께는 뺀 근사값이다.)
- 쓴 색은 모두 기존 토큰이다. 새 색 · 그림자 없음.

## 4. 다시 잰 표 (그림 쪽 조건)
| 줄 | 팔이 머리를 가리는 포즈(5개 · 기본 서기) | 15° 분해능 | 판정 |
|---|---|---|---|
| A 동글이 | 2 / 5 (점프 · 머리 위 하트) · 기본 서기 0 | 0.29칸 | 포즈 그림 ✗ · 브랜드 얼굴 ✓ |
| C 옛 6등신 | 0 / 5 (없음) · 기본 서기 0 | 0.78칸 | 포즈 그림 ✓ · 뻣뻣함(결정권자 의견) |
| C 걷는이 5등신(새) | 0 / 5 (없음) · 기본 서기 0 | 0.53칸 | 포즈 그림 ✓ · 머리 가림 0 유지 · 분해능은 A보다 높고 옛 C보다 낮음 |

- **판정 방법**: 아래팔(팔꿈치→손목)과 머리 원의 거리가 머리 반지름 + 팔 굵기의 20%보다 가까우면 "가림". 이 방법은 v1과 같다.
- **새 C에서 손 · 팔 바깥선이 머리 원에 닿는 칸은 없다**(손 원 · 팔 굵기까지 넣어 따로 쟀다). 가장 가까운 칸은 머리 위 하트 — 손과 머리 사이 1.9, 아래팔 바깥선과 머리 사이 1.0(키 240px에서 약 5px · 2px). 처음 넣은 하트 각도는 손이 머리 가장자리에 닿아서 넓혔다. 머리는 몸보다 위에 그려서 얼굴이 팔에 가려지는 일은 없다.
- 분해능은 "클수록 각도 차이가 눈에 띈다"의 상대 비교다. 어느 값부터 따라 하기에 충분한지는 시험으로 정해야 한다(기준 값을 만들어 두지 않았다).
- 새 C의 얼굴은 키 240px에서 머리 지름 약 48px(A는 96px). **표정은 A의 큰 머리로** 6가지(웃기 · 윙크 · 볼 빵빵 · 깜짝 · 활짝 · 메롱, ③-C3).
- **머리를 더 키우면?** 지금 각도로는 머리 지름 24%(약 4.2등신)까지 가림 0이고 25%에서 머리 위 하트가 가린다(다리 길이를 줄여 키 100을 맞춰서 잰 값). 더 당기고 싶으면 이 안에서 정하면 되고, 그보다 크면 하트 각도를 다시 맞춰야 한다.

## 5. 겹침 윤곽 (§6-3)
- **모양**: 실루엣 합집합의 **테두리만**. 사람마다 따로 만든다(몸이 닿아도 한 덩어리가 되지 않음). 몸 · 팔다리 두께는 그림의 1.22배로 키워 실제 몸에 여유를 준다(옛 C는 1.3배였고, 새 C가 더 통통해서 줄였다).
- **값**: 흰 테 3px(그림 크기와 상관없이 같은 두께) + 어두운 테 1.6px(잉크 65%) + 안쪽 흰 10%. 얼굴 · 핀 · 목도리 · 가방은 윤곽에 안 넣는다.
- **배경 위에서 보이나** (흰 테 대비 · 어두운 테 대비 중 큰 값, 비텍스트 3 기준)

| 배경 | 흰 테 | 어두운 테 | 보이는 정도 |
|---|---|---|---|
| 밝은 하늘 #E8F0FA | 1.15 | 5.10 | 5.10 |
| 중간 돌벽 #8A9199 | 3.19 | 3.08 | 3.19 (가장 낮음) |
| 어두운 밤 #1F2937 | 14.68 | 1.13 | 14.68 |
| 줄무늬 #D1D5DB / #4B5563 | 두 색에서 각각 계산 | | 4.61 (나쁜 쪽) |
- 돌벽 3.19는 기준선에 가깝다. 이 정도 중간 밝기 배경이 가장 어렵다는 뜻이니 **실제 카메라 영상으로 확인**이 필요하다(보드의 배경은 색 견본이다).

## 6. 어두운 바탕용 흰 윤곽 변형 (③-C1 아래쪽)
- **모양**: 같은 몸 · 같은 얼굴. 몸 전체(잉크 윤곽 · 핀 · 목도리 꼬리 포함) 바깥에 **흰 테 한 겹**을 더 둘렀다. 두께 = 키의 1.2%, 최소 1.5px(키 80px → 1.5px, 키 240px → 2.9px). 바닥 그림자는 흰색 14%.
- **대비**: 흰 테 ÷ 어두운 바탕 #1F2937 = 14.7(3 이상 필요). 기본(잉크 윤곽)은 같은 바탕에서 윤곽 · 핀이 묻혀서 흰 점처럼만 보인다(③-C1에서 나란히 확인).
- **작게**: 키 48px에서는 사람 모양 · 핀 · 목도리까지 보이고(C는 머리가 작아 눈 · 입이 점에 가깝다), 24px에서는 표정이 안 읽히고 사람 모양 · 핀 윤곽만 읽힌다.
- **쓸 곳**은 아직 정하지 않았다(어두운 화면이 생길 때 같이 정함). 만드는 데 새 색은 없다(흰 · 기존 잉크).

| ④ 서버 업로드 없음 | 화면에 영향 없음 | 구현 규칙 |
| [가이드] 토글 (11-13) | 오른쪽 위 알약 44 + 스위치 52×32. 켜면 윤곽 · 보조선, 끄면 맨 화면 | 제안 |
| 셀피 좌우 뒤집힘 | 그리지 않음. 앞 카메라에서 윤곽 좌우를 같이 뒤집으면 됨(`mirror`) | 구현 규칙 |
- 윤곽은 새 C 둘이 하트(키 380px 기준, 점선 상자 안). 카메라 영상은 색 견본(실제 장소가 아님). 누르는 영역은 모두 44 이상(닫기 · 가이드 · 손잡이 · 갤러리 · 뒤집기 · 셔터 72). 흰 글자는 반투명 잉크 판(55~62%) 위에 둬서 가장 밝은 하늘 위에서도 4.67 이상(위쪽 상태 표시줄은 위 가림막 위에서 7.1).

## 8. PM이 정할 것
1. **새 C가 A와 어울리는지(눈으로 확인).** 숫자로는 머리 17% → 20%, 팔 굵기 · 손발 키움, 굽힌 자세까지 왔다. 더 당기려면 §4의 "머리를 더 키우면"(지금 각도로 머리 24%까지 가림 0)과 팔 굵기가 손잡이다. 대가는 15° 분해능(지금 0.53칸).
2. 어두운 화면용 흰 윤곽 변형을 **어디에** 쓸지(지금은 쓸 곳을 정하지 않음).
3. 닮은 캐릭터 확인 담당과 시점(앱에 넣기 전).
4. 앱에서 포즈를 **각도 데이터로 그릴지(앱에 뼈대 코드)** 이미지(SVG/PNG)로 내보낼지 — frontend 결정. 나는 지금 코드로 만들어 둬서 둘 다 가능하다.
5. 캐릭터가 나오는 화면의 주황 계산에 목도리를 넣는다는 한 줄을 DESIGN-001에 넣을지.

## 9. 한계 · 열린 것
1. **따라 찍기 시험을 안 했다.** "겹친 윤곽만 보고 2분 안에 따라 찍을 수 있나 · 가이드 없는 사진보다 나은가"는 §6 진행 방법대로 서울 3곳에서 실제로 찍어 봐야 안다. 지금 숫자는 그림에서 판단한 것뿐이다.
2. **닮은 캐릭터 확인을 못 했다.** 도형이 단순해서 우연히 닮은 것이 있을 수 있다. 쓰기 전에 이미지 · 상표 검색이 필요하다(나는 할 수 없다).
3. **키 · 체형은 모두 같다**(§6-1 방침). 실제 일행의 키 차이는 손가락으로 크기를 맞추는 것으로 대신한다.
4. 24px에서는 얼굴이 점이 된다 → 작은 자리에는 핀 하나만 쓰는 편이 낫다(제안, 시험 전).
5. 이름(동글이 · 걷는이)은 작업 이름이다. B 중간이는 이번 결정으로 뺐고 기록 보드(③-C1v1)에만 남겼다.
6. v1 기록 보드의 숫자(A 2/5 · B 1/5 · 옛 C 0/5 · 분해능 0.29 · 0.58 · 0.78)는 옛 각도 기준이다. v2 표는 각도가 달라서 그대로 이어서 비교하지 않는다.

## 10. 점검
- 보드 6장(C1~C4 + 기록 2장) 가로 넘침 없음 · 글자 12 이상 · 누르는 영역 44 미만 없음(③-C4).
- 모두 SVG · HTML로 그렸다. 새 색 · 그림자 없음(그림자 타원은 기존 토큰 #E5E7EB).
- 숫자(비율 · 가림 · 분해능 · 대비 · 주황 면적 · 손끝 간격)는 모두 `gen_char.py`의 뼈대에서 계산했다.
- 하트 각도 · 머리 키우기 한계는 코드로 여러 각도를 돌려 찾았다.
