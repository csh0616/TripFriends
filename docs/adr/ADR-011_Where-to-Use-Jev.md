# ADR-011 · Jev를 어디에 쓸지 (측정 기반)

| 항목 | 내용 |
|---|---|
| 상태 | **승인** — PM 2026-11-02 제안, 결정권자 승인 2026-11-02 |
| 근거 | POC-001 §5(예비), §6(재측정 v2), §7(역할 C), §8(역할 D). 결정권자 맥에서 실측, 총 약 500회 호출, 비용 약 $0.01 |
| 관련 | SRS-001 FR-02c·10a·21·24 · ADR-013 · PRD-001 §4 · PORTFOLIO D-20, M-21 |

## 1. 결정
| 역할 | 결정 | 근거 (숫자) | 적용 |
|---|---|---|---|
| A. 대화/요청 판단 | **Jev 채택**: 대화/요청 2분류, **확신 0.6 미만이면 되묻기** | 명확 문장 92.3% (기준 90%), 애매한 문장일수록 확신 낮음 (0.91 vs 0.79). 3분류는 71%로 미달 | R2 대화 라우터 첫 판단 노드 (안전 규칙 다음) |
| B. 방향 해석 | **Jev 하나 고르기 채택 + Jev가 unknown이면 키워드 규칙** | 편향 없는 새 문장: 규칙 50% vs Jev 90%. Jev가 unknown을 낸 짧은 속어 5개는 규칙이 모두 맞춤 → 조합 88% (사후 계산) | R1은 키워드 규칙만, R2에서 Jev + 규칙 보조 |
| B'. 여러 방향 동시 판단 (예/아니오) | **보류** | 하나라도 맞음 90%지만 정확 일치 52%, 엉뚱한 방향을 자주 더함 | 기준값을 올려 다시 측정할 때까지 미사용 |
| C. 후보 맞춤 점수 | **규칙 유지 (Jev 기각)** | 상위 3 겹침 규칙 55.6% vs Jev 61.1% (+5.5%p, 기준 +15%p 미달), 1위 적중 규칙 67% vs Jev 50%, 확신 평균 0.57 (POC-001 §7) | R1·R2 규칙 가중치. 실제 장소 설명이 생기면 R2에서 [좋아] 비율로 재측정 |
| D-1. 요청 문장 → 메인 카드 | **Jev 채택** (choice, 확신 0.6 미만 되묻기) | 요청 7개: Jev 100% vs 키워드 규칙 42.9% (POC-001 §8) | R2 대화. R1은 계획 대화 외 자유 입력 없음 |
| D-2. 애매 상황 → 메인 카드 | **Jev 기각** → 상황 규칙 후보 | 말 없는 애매 상황 8개: Jev 37.5% (기준 없이). '다음 일정'에 끌리고 숨은 필요(식사·피로)를 놓침 | R1·R2 규칙. 새 상황 검증에서 규칙도 33% → 강한 신호 4개만 메인, 나머지는 제안 칩 (SCREEN-001 §4-2a) |
| D-3. 보조 카드 | **규칙** (짝 표) | 여러 장 동시 판단 보류(B') | SCREEN-001 §5 |
| 안전·사실 값·코스 계산 | **Jev 쓰지 않음** | 원칙 (틀리면 안 되는 곳) | 규칙·DB·DP |

## 2. 운영 값
| 항목 | 값 | 근거 |
|---|---|---|
| 확신 기준 (A) | 0.6 | 측정 전 고정. 0.5면 정확도는 오르지만 되묻기가 사라짐 |
| 시간 제한 (대화 라우터) | **0.8초**, 넘으면 "요청"으로 보고 엔진 처리 (가설) | 실측 p50 445ms, p95 630ms. 기존 가드레일 0.5초는 p95를 못 견딤 |
| 시간 제한 (화면 조합 G-5) | 역할 D 측정 후 결정 | — |
| 비용 | 호출당 약 $0.00002 | 실측. 가설($0.00008)의 1/4 |

## 3. 검토한 대안
| 안 | 판단 |
|---|---|
| 모든 판단을 LLM에 | 느리고 비쌈. 이번 측정 범위에선 Jev로 기준 달성 → 기각 (LLM 비교는 역할 D에서 참고 측정) |
| 모든 판단을 규칙에 | 새 표현을 못 잡음 (방향 해석 50%) → 기각 |
| **규칙 + Jev 역할 분담** | 분명한 곳은 규칙, 표현이 다양한 곳은 Jev, 틀리면 안 되는 곳은 규칙·DB → **채택** |

## 4. 한계
- 정답 데이터가 작다 (A 35문장, B 50문장). 새 20문장은 다른 AI 한 명이 채점
- "Jev + 규칙 보조" 88%는 결과를 보고 만든 조합이라, 새 문장으로 다시 확인해야 한다
- 실제 사용자 문장이 아니다 → R2 파일럿 대화 기록으로 다시 측정 (M-21)

## 포트폴리오 포인트
- **보여주는 것**: AI를 넣을 자리를 측정으로 정함. 질문 설계 변경으로 71% → 92%. 문장을 보고 짠 규칙(87%)이 공정한 데이터에선 50%로 떨어진 것을 잡아냄
- **예상 면접 질문**
  - "왜 LLM이 아니라 Jev를 썼나요?" → "고르기형 판단이라 출력이 정해진 모델이 빠르고 쌌다. 같은 정답 데이터에서 기준(90%)을 넘었고 호출당 $0.00002, 중앙값 0.45초였다"
  - "규칙보다 AI가 낫다는 걸 어떻게 확인했나요?" → "처음엔 규칙이 이겼는데, 규칙을 만든 사람이 테스트 문장을 보고 만든 탓이었다. 규칙을 동결하고 다른 AI가 새 문장을 쓰게 해서 다시 재니 규칙 50%, Jev 90%였다"
